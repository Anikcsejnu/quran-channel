        OAuth client

        Stored only on this computer, in %USERPROFILE%\.quran-channel\youtube.json — never in the project or the browser.

        One-time Google setup

        ~10 min
        1. Open Google Cloud Console and create a project (e.g. “Quran Studio”).
        2. Enable YouTube Data API v3.
        3. OAuth consent screen: type External, add your Gmail as a test user, then Publish app (otherwise sign-in expires every 7 days).
        4. Create OAuth client → application type Desktop app. Paste its ID and secret into OAuth client.
        5. Click Connect YouTube and allow access. Google may warn that the app isn’t verified — it’s your own app: Advanced → Go to …
        Uploads stay Private until Google audits your project. Apply with the YouTube API audit form. Until then, publish each video yourself in YouTube Studio — a good moment to check the copyright Checks result.
